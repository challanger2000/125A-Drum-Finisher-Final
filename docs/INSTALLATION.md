# 125A Drum Finisher V1.0.0 — Installation (Windows x64)

## Requirements

Windows x64 and a VST3-capable DAW with support for stereo audio-effect plugins. This release has been automatically tested as a Windows x64 VST3. Other platforms have not been certified.

## Installation

1. Close your DAW.
2. Extract the full Gumroad distribution ZIP.
3. Copy the **complete** `125A_Drum_Finisher.vst3` bundle to `C:\\Program Files\\Common Files\\VST3\\`. Do not extract or rename individual internal files.
4. Restart the DAW. If necessary, update the VST3 plugin scan.
5. Insert **125A Drum Finisher** on a stereo drum channel or stereo drum bus.

## Update / removal

Close the DAW before replacing or removing the plugin bundle. Back up any projects that depend on this release before installing a later incompatible version. To uninstall, remove the plugin bundle from the VST3 folder with the DAW closed.

## Troubleshooting

If the plugin is not listed, check that the complete VST3 folder was copied, the host is 64-bit, and a fresh plugin scan was performed. If the editor cannot be displayed, check host graphics/scaling configuration. No external installer is needed for this bundle.
